# pourbaix — no longer supported

**This package is no longer maintained or supported. It has been superseded by
[luapourbaix](https://github.com/cjorssen/luapourbaix). Please use luapourbaix
for new work and migrate existing documents to its documented interface.**

The luapourbaix successor is being prepared for publication; its GitHub repository
is the destination for the new package. A public release is not available there
yet.

The original **pourbaix was published only on GitHub. It was never distributed
through CTAN.** This notice concerns this legacy repository, not a CTAN package.

The source files and PDF manuals in this repository describe the unsupported
legacy implementation and are kept for historical reference. They are not the
luapourbaix documentation. Migration requires adapting to the new interface;
changing the package name alone is not sufficient.
